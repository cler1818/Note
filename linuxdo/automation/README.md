# LINUX DO 浏览器批量运行脚本

本目录配合已经安装的 LINUX DO 助手 **1.3.8** 使用，更新日期：2026-10-16。

## 安装和配置

1. 将本目录的文件放在同一文件夹，安装 Python 和 `requirements.txt` 中的依赖：
   `py -m pip install -r requirements.txt`
2. VirtualBrowser 的本机 API 服务使用 `http://localhost:9000`。
3. GitHub 版本从环境变量读取本机 API 密钥。在 PowerShell 中运行：

   ```powershell
   $env:VIRTUAL_BROWSER_API_KEY = '填写自己的本机 API 密钥'
   .\运行.bat
   ```

   也可以用 Windows 用户环境变量保存 `VIRTUAL_BROWSER_API_KEY`，然后双击 BAT。
4. 浏览器环境需已安装并启用 [LINUX DO 助手 1.3.8](../linux-do-helper.user.js)，论坛未登录的账号先手动登录。

## BAT 第一项：全部运行并自动补跑一次

- 默认最多同时 9 个浏览器，自定义并发可以选择 1–9。
- 首轮全部完成后，把当轮“有问题的环境”自动再运行一次。失败、限流拒绝和运行中接口限流都纳入这一次补跑。
- 两轮结束后生成一次综合汇总。按浏览器编号统计：任一轮成功就计为成功，两轮均失败才计为失败。
- 主题、阅读篇数和点赞累计两轮成果；首轮已有成果在补跑失败时保留。
- 补跑成功且没有继续限流的环境，从最终问题清单移除。
- Ctrl+C 中断后取消自动补跑。第二项指定补跑和 `--test` 仍只运行一轮。

## 日志

所有日志和等级明细保存在同一份 `log/autorun_log_日期.txt`，最新综合汇总置顶。

“有问题的环境”先列未登录的编号，再列其他问题；每组按编号升序，每行最多 9 个，标题和总数只写一次。根据最后一轮明确的登录状态或原因分类，CF 和网络错误不计作未登录。

例如 105、120 未登录：

```text
【有问题的环境】11 个: 105,120,23,27,28,31,63,66,70
76,89
```

访问天数至少 50 天的浏览器编号及等级条件缺项明细继续写在同一日志中。
